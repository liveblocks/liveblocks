Liveblocks Feeds are realtime, persistent message streams inside a room. Use
them for chat interfaces, agent output, activity logs, and workflows that need
to send structured messages between your server and connected clients.

<Banner title="Start building with Feeds" type="info">

Follow the [Next.js Feeds get-started guide](/docs/get-started/nextjs-feeds),
then use the pages below to design the interface and workflow around your feeds.
