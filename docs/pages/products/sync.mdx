Add realtime collaboration to any application with Sync. Multiple users can edit
artifacts at the same time, and all changes are automatically synchronized and
persisted. Use cases include rich-text editors, design tools, whiteboards,
forms, flowcharts, spreadsheets, and fully custom interfaces.
