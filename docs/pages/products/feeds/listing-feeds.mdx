Use [`useFeeds`](/docs/api-reference/liveblocks-react#useFeeds) to render the
feeds in the current room. Results update in realtime when feeds are created,
updated, or deleted.

```tsx title="FeedList.tsx"
import { useFeeds } from "@liveblocks/react/suspense";

export function FeedList() {
  const { feeds } = useFeeds({
    metadata: { kind: "chat" },
    limit: 20,
  });

  return (
    <nav>
      {feeds.map((feed) => (
        <a key={feed.feedId} href={`/chat/${feed.feedId}`}>
          {feed.metadata.title ?? feed.feedId}
        </a>
      ))}
    </nav>
  );
}
```

## Filter feeds [#filter-feeds]

Pass `metadata` to return feeds whose metadata contains every provided key/value
pair. Use `since` to return feeds created or updated after a timestamp.

```tsx
const { feeds } = useFeeds({
  metadata: { project: "acme", kind: "workflow" },
  since: Date.now() - 24 * 60 * 60 * 1000,
});
```

Metadata filters are exact matches. Store fields you will query directly in feed
metadata, and keep larger or frequently changing data elsewhere.

## Create and rename feeds [#create-and-rename]

Create a feed with
[`useCreateFeed`](/docs/api-reference/liveblocks-react#useCreateFeed) and update
its metadata with
[`useUpdateFeedMetadata`](/docs/api-reference/liveblocks-react#useUpdateFeedMetadata).

```tsx
const createFeed = useCreateFeed();
const updateFeedMetadata = useUpdateFeedMetadata();

createFeed("design-review", {
  metadata: { kind: "chat", title: "Design review" },
});

updateFeedMetadata("design-review", {
  kind: "chat",
  title: "Final design review",
});
```

Use [pagination](/docs/products/feeds/pagination) when a room can contain more
feeds than should be loaded at once.
