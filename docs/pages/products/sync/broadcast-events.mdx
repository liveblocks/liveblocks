Broadcast events are transient messages sent to the other connected clients in a
room. Use them for actions that should happen now but do not need to be stored
as part of the document.

Examples include starting media playback, showing confetti, invalidating cached
server data, or announcing that an external workflow finished.

## Send and receive events [#send-and-receive-events]

Send an event with
[`useBroadcastEvent`](/docs/api-reference/liveblocks-react#useBroadcastEvent)
and receive it with
[`useEventListener`](/docs/api-reference/liveblocks-react#useEventListener).

```tsx
import {
  useBroadcastEvent,
  useEventListener,
} from "@liveblocks/react/suspense";

function VideoControls() {
  const broadcast = useBroadcastEvent();

  useEventListener(({ event }) => {
    if (event.type === "PLAY_VIDEO") {
      player.play();
    }
  });

  return (
    <button onClick={() => broadcast({ type: "PLAY_VIDEO" })}>
      Play for everyone
    </button>
  );
}
```

Define the `RoomEvent` interface in `liveblocks.config.ts` to type event
payloads throughout the application.

```ts file="liveblocks.config.ts"
declare global {
  interface Liveblocks {
    RoomEvent: { type: "PLAY_VIDEO" } | { type: "REVALIDATE"; key: string };
  }
}

export {};
```

## Revalidate API data with SWR [#revalidate-api-data-with-swr]

When a server mutation changes data outside Storage, broadcast its cache key so
the other clients revalidate it.

```tsx
import { useEventListener } from "@liveblocks/react/suspense";
import { useSWRConfig } from "swr";

function RevalidateFromRoomEvents() {
  const { mutate } = useSWRConfig();

  useEventListener(({ event }) => {
    if (event.type === "REVALIDATE") {
      mutate(event.key);
    }
  });

  return null;
}
```

Read [Revalidate API data with SWR](/docs/guides/revalidate-api-data-with-swr)
for the full pattern.

## When not to use broadcasts [#when-not-to-use-broadcasts]

Broadcast events are not persisted. Clients that are disconnected do not replay
earlier events after joining.

Use:

- [Storage](/docs/products/sync/data-types) for durable document state
- [Presence](/docs/products/sync/presence) for current per-connection state
- [Feeds](/docs/products/feeds) for persisted realtime message streams

The client API also exposes
[`Room.broadcastEvent`](/docs/api-reference/liveblocks-client#Room.broadcastEvent)
for non-React applications.
