Multiplayer undo/redo lets each user reverse their own document changes without
rolling back edits made by other people. Sync maintains a history for each room
connection and applies undo operations through the same conflict-resolution
model as other Storage mutations.

for a step-by-step implementation.

## Add undo and redo [#add-undo-and-redo]

Use [`useHistory`](/docs/api-reference/liveblocks-react#useHistory) to read the
current history state and call its actions.

```tsx
import { useCanRedo, useCanUndo, useHistory } from "@liveblocks/react/suspense";

function HistoryControls() {
  const { undo, redo } = useHistory();
  const canUndo = useCanUndo();
  const canRedo = useCanRedo();

  return (
    <>
      <button disabled={!canUndo} onClick={undo}>
        Undo
      </button>
      <button disabled={!canRedo} onClick={redo}>
        Redo
      </button>
    </>
  );
}
```

You can also use [`useUndo`](/docs/api-reference/liveblocks-react#useUndo),
[`useRedo`](/docs/api-reference/liveblocks-react#useRedo),
[`useCanUndo`](/docs/api-reference/liveblocks-react#useCanUndo), and
[`useCanRedo`](/docs/api-reference/liveblocks-react#useCanRedo) separately.

## What belongs in history [#what-belongs-in-history]

Storage mutations are added to history by default. Remote collaborators’ edits
are not added to your local undo stack, so undoing a shape move does not remove
a label another person added.

Presence is temporary and is not normally undoable. For exceptional cases, you
can add a Presence update to history through the Presence API.

## Group continuous interactions [#group-continuous-interactions]

Dragging or resizing can produce many small updates. Pause history at the start
of the interaction and resume it at the end so one undo reverses the whole
gesture.

```tsx
import { useHistory } from "@liveblocks/react/suspense";

function DraggableShape() {
  const { pause, resume } = useHistory();

  return <Shape onDragStart={pause} onDrag={updateShape} onDragEnd={resume} />;
}
```

A single [`useMutation`](/docs/api-reference/liveblocks-react#useMutation)
callback is also batched as one history entry.

## Keyboard shortcuts [#keyboard-shortcuts]

Connect `undo` and `redo` to the conventions of your platform:

- macOS: Command–Z and Command–Shift–Z
- Windows and Linux: Control–Z and Control–Y or Control–Shift–Z

Disable shortcuts while an input or editor owns its own history.

## Client API [#client-api]

Non-React applications can use
[`Room.history`](/docs/api-reference/liveblocks-client#Room.history) directly.
Redux and Zustand integrations expose equivalent history controls in their API
references.
