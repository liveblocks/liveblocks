Sync supports collaborative text editing, merging simultaneous keystrokes
character by character so multiple people, and AI agents, can type in the same
text without overwriting each other. There are two ways to add text editing:
[LiveText](#livetext), the recommended choice for new applications, and
[Yjs](#yjs), for editors that require the Yjs ecosystem.

## LiveText [#livetext]

[`LiveText`](/docs/api-reference/liveblocks-client#LiveText) is the
conflict-free rich text data type inside [Storage](/docs/products/sync/storage).
Because it’s part of the document tree, text fields live alongside your other
data—a document can hold captions on shapes, cells in a table, or several full
editors, each edited collaboratively and independently.

### Connect an editor [#connect-an-editor]

Editor packages connect popular text editors to LiveText, adding realtime
collaboration, live cursors, comments, mentions, and ready-made toolbars.

- [`@liveblocks/react-tiptap`](/docs/api-reference/liveblocks-react-tiptap)
- [`@liveblocks/react-lexical`](/docs/api-reference/liveblocks-react-lexical)
- [`@liveblocks/react-blocknote`](/docs/api-reference/liveblocks-react-blocknote)

For example, here’s a collaborative Tiptap editor. Passing
[`collaborationMode: "liveblocks"`](/docs/api-reference/liveblocks-react-tiptap#Liveblocks-collaboration-mode)
stores the editor’s text as `LiveText` backed by Storage.

```tsx
"use client";

import {
  FloatingToolbar,
  useLiveblocksExtension,
} from "@liveblocks/react-tiptap";
import { useEditor, EditorContent } from "@tiptap/react";
import StarterKit from "@tiptap/starter-kit";

function TextEditor() {
  // +++
  const liveblocks = useLiveblocksExtension({
    collaborationMode: "liveblocks",
  });
  // +++

  const editor = useEditor({
    extensions: [
      liveblocks,
      StarterKit.configure({
        // The Liveblocks extension comes with its own history handling
        undoRedo: false,
      }),
    ],
    immediatelyRender: false,
  });

  return (
    <div>
      <EditorContent editor={editor} />
      // +++
      <FloatingToolbar editor={editor} />
      // +++
    </div>
  );
}
```

To render multiple editors on one page, give each a separate
[`field`](/docs/api-reference/liveblocks-react-tiptap#Multiple-editors) value.
Follow the [Tiptap](/docs/get-started/nextjs-tiptap-storage),
[Lexical](/docs/get-started/nextjs-lexical-storage), or
[BlockNote](/docs/get-started/nextjs-blocknote) get started guides for a full
setup, or read the [text editor use case](/docs/use-cases/text-editor) to see
every feature in place.

### Text fields in your document [#text-fields]

You don’t need a full editor to use LiveText. Declare fields directly in your
`Storage` type for smaller pieces of collaborative text, such as a caption on a
shape or a cell in a table.

```tsx file="liveblocks.config.ts"
import { LiveText } from "@liveblocks/client";

declare global {
  interface Liveblocks {
    // +++
    Storage: {
      summary: LiveText;
    };
    // +++
  }
}
```

Edit the text inside a [mutation](/docs/products/sync/storage#updating-storage),
and concurrent keystrokes from other users are merged automatically.

```tsx
import { useMutation } from "@liveblocks/react/suspense";

function Summary() {
  const appendText = useMutation(({ storage }, text: string) => {
    // +++
    const summary = storage.get("summary");
    summary.insert(summary.length, text);
    // +++
  }, []);

  // ...
}
```

### Edit text from the server [#edit-text-from-the-server]

Because the text lives in Storage, your back end and AI agents can edit it with
[`Liveblocks.mutateStorage`](/docs/api-reference/liveblocks-node#mutate-storage),
using the same `LiveText` API as the client. Connected users see the result in
realtime.

```ts
import { Liveblocks } from "@liveblocks/node";

const liveblocks = new Liveblocks({
  secret: process.env.LIVEBLOCKS_SECRET_KEY!,
});

// +++
await liveblocks.mutateStorage("my-room-id", ({ root }) => {
  const summary = root.get("summary");
  summary.insert(summary.length, " Approved by the review team.");
  summary.format(0, 8, { bold: true });
});
// +++
```

Learn more under [server-side editing](/docs/products/sync/server-side-editing)
and [agentic editing](/docs/products/sync/agentic-editing).

## Yjs [#yjs]

[Liveblocks Yjs](/docs/products/sync/text-editing/yjs) connects a room to a
`Y.Doc`, Liveblocks persisting and synchronizing the Yjs document for you.
Choose Yjs instead of LiveText when an editor binding expects a `Y.Doc`—such as
[Slate](/docs/get-started/yjs-slate-react),
[Quill](/docs/get-started/yjs-quill-react),
[Monaco](/docs/get-started/yjs-monaco-react),
[SuperDoc](/docs/get-started/yjs-superdoc-react), or
[CodeMirror](/docs/api-reference/liveblocks-codemirror)—or when you need Yjs
shared types, awareness, or an established Yjs ecosystem.

Our Tiptap, Lexical, and BlockNote packages also support Yjs-backed
collaboration, which is currently required for their
[offline support](/docs/api-reference/liveblocks-react-tiptap#Offline-support)
and [AI toolbar](/docs/api-reference/liveblocks-react-tiptap#AiToolbar)
features. Read the [Yjs page](/docs/products/sync/text-editing/yjs) for details.
