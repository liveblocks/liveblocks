Create a collaborative canvas, whiteboard, or design tool with Liveblocks. Start
with a ready-made canvas, or create something custom. Add draggable objects,
show live cursors, use version history, and add multiplayer undo/redo.

## Features [#features]

- **Realtime collaboration**: Canvas state is permanent and updates in realtime
  for connected users.
- **Version history**: Save, preview, and restore canvas state from snapshots.
- **Multiplayer undo/redo**: Each user can independently undo and redo their own
  changes.
- **Agentic editing**: Create AI agents that can modify the canvas from the
  back-end.
- **Presence**: Show live cursors, avatar stacks, realtime selections, and agent
  activity.
- **Comments**: Add draggable commenting threads to the canvas.
- **Permissions**: Control which users can read and edit the canvas.

## What Liveblocks adds to a canvas [#features]

### Synchronize shapes and layers [#synchronize-shapes]

Store shapes in a [`LiveMap`](/docs/api-reference/liveblocks-client#LiveMap),
keyed by stable IDs, so users can create, move, and delete different objects
concurrently. Model each shape as a
[`LiveObject`](/docs/api-reference/liveblocks-client#LiveObject), and use a
[`LiveList`](/docs/api-reference/liveblocks-client#LiveList) when the order of
layers is also shared.

```tsx
const shapes = useStorage((root) => root.shapes);

const moveShape = useMutation(
  ({ storage }, id: string, x: number, y: number) => {
    storage.get("shapes").get(id)?.update({ x, y });
  },
  []
);
```

Storage mutations are applied optimistically and synchronized through Sync. Read
[Data types](/docs/products/sync/data-types) and
[Conflict resolution](/docs/products/sync/conflict-resolution) when designing
the canvas document.

### Show cursors and selections [#presence]

Use [Presence](/docs/products/sync/presence) for cursor coordinates, selected
shape IDs, active tools, and other temporary signals. Presence updates reach
other users in realtime and disappear when a connection ends, so they do not
become part of the saved canvas.

### Add multiplayer undo and redo [#undo-redo]

Liveblocks keeps a history for each user, allowing them to undo their own
changes without reversing work from other collaborators. Pause history when a
drag starts and resume it when the drag ends, so every pointer movement is
synchronized while the complete gesture remains one undo step. Read
[Multiplayer undo/redo](/docs/products/sync/multiplayer-undo-redo) for the React
and client APIs.

### Discuss objects in context [#comments]

Use [Comments](/docs/products/comments) to attach threads to coordinates,
shapes, or regions. Store a canvas position or object ID in thread metadata,
then render each thread at its corresponding point or object.

### Save and automate changes [#versions-and-agents]

[Version history](/docs/products/sync/version-history) creates restore points
for the whole canvas. Servers and AI agents can use
[Agentic editing](/docs/products/sync/agentic-editing) to modify the same
Storage document as connected users, with their changes appearing in realtime.
