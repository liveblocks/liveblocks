Collaborative code editors need character-level synchronization, shared
awareness, and editor-specific selection handling. Use the Liveblocks Yjs
provider with CodeMirror or Monaco, then add Comments or Notifications around
the editing experience.

<Banner title="Choose an editor guide" type="info">

Start with [CodeMirror and React](/docs/get-started/yjs-codemirror-react) or
[Monaco and React](/docs/get-started/yjs-monaco-react). Guides are also
available for JavaScript, Svelte, and Vue.

</Banner>

## APIs you need [#apis]

- [`getYjsProviderForRoom`](/docs/api-reference/liveblocks-yjs#getYjsProviderForRoom)
  to connect a `Y.Doc` to the current room
- A Yjs binding for CodeMirror or Monaco
- Yjs Awareness for cursors and selections
- [Comments](/docs/products/comments) for review discussions
- [Notifications](/docs/products/notifications) for mentions and updates

```tsx
const room = useRoom();
const provider = getYjsProviderForRoom(room);
const yText = provider.getYDoc().getText("code");

const extensions = [
  yCollab(yText, provider.awareness, {
    undoManager: new Y.UndoManager(yText),
  }),
];
```

Use one room per collaborative file or choose a stable naming convention for
multiple text values in one room. Keep language-server or build output outside
the shared document unless collaborators need to edit it.
