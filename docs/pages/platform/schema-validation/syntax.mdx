<Banner type="warning" title="Schema validation was sunsetted">
  Schema validation and the Liveblocks schema language are no longer available.
  They were removed on May 1st, 2025. For persistent collaborative state, use
  [Storage](/docs/products/sync/storage) instead.
</Banner>

For historical context about the feature, see the
[Launch Week 2 wrap-up](https://liveblocks.io/blog/launch-week-2-wrap-up#schema-validation).
