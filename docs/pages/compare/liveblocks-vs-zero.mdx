[Rocicorp Zero](https://zero.rocicorp.dev/docs) is a local-first sync engine
that caches queries and mutates data against a backend. Liveblocks is a hosted
sync engine for collaborative documents with conflict resolution, presence, and
editor integrations.

Zero optimizes for fast query-driven UIs with cached reads and writes. Liveblocks
optimizes for multiplayer editing on shared documents.

## At a glance [#at-a-glance]

| | Liveblocks | Zero |
| --- | --- | --- |
| Primary purpose | Collaborative sync engine | Cached query sync |
| Data model | Room-based collaborative documents | Queries and mutations |
| Conflict resolution | Built-in for Storage and Yjs | Server-authoritative mutations |
| Best for | Editors, canvases, agents | Local-first apps with query caches |

## When to choose Liveblocks [#when-to-choose-liveblocks]

Choose Liveblocks when you need:

- **Simultaneous edits** on the same document with
  [conflict resolution](/docs/guides/how-conflict-resolution-works-in-liveblocks-sync)
- **Collaboration products** including [Presence](/docs/products/sync/presence),
  [Comments](/docs/products/comments), and [Notifications](/docs/products/notifications)
- **Editor integrations** through [Sync integrations](/docs/products/sync/integrations)
- **Yjs, LiveText, or Storage** for structured and text collaborative state
- **Version history** and [server-side editing](/docs/products/sync/server-side-editing)

## When to choose Zero [#when-to-choose-zero]

Choose Zero when you need:

- **Instant query results** from a local cache with background sync
- **Mutation-driven apps** where the server resolves writes
- **Local-first architecture** aligned with Rocicorp's sync model
- **Table-oriented data** rather than CRDT document editing

## Feature comparison [#feature-comparison]

| Feature | Liveblocks | Zero |
| --- | --- | --- |
| Collaborative documents | [Storage](/docs/products/sync/storage), Yjs | Query results and rows |
| CRDT merges | Built-in | Application-level |
| Presence | [Presence](/docs/products/sync/presence) | Build custom |
| Comments | [Comments](/docs/products/comments) | Build custom |
| Text editors | [Integrations](/docs/products/sync/integrations) | Build custom |
| Offline | Sync client reconnect and optimistic updates | Local cache with sync |
| Server-side logic | [Node.js SDK](/docs/api-reference/liveblocks-node), webhooks | Your backend + Zero |
| Authentication | [Liveblocks authentication](/docs/api-reference/authentication) | Your auth layer |
| Agentic editing | [Agentic editing](/docs/products/sync/agentic-editing) | Application-level |

## Pricing [#pricing]

Liveblocks uses [plans and credits](/docs/pricing/plans). Zero pricing and
hosting depend on your Rocicorp deployment; see
[Zero documentation](https://zero.rocicorp.dev/docs) for details.

## Deployment [#deployment]

Liveblocks is managed with optional
[self-hosting](/docs/platform/data-storage#Self-hosting).

Zero requires deploying the sync stack described in
[Zero docs](https://zero.rocicorp.dev/docs) alongside your backend.
