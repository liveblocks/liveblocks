Liveblocks is a realtime collaboration platform that allows you to build
multiplayer applications where users and agents can work together. It provides a
sync engine that powers shared documents, text editing, presence, and more.
These guides compare it with the databases, sync engines, messaging services,
and editor back ends you may already use, and say when to pick one, the other,
or both.

## Databases [#databases]

| Comparison                                       | Read it when                                                                                  |
| ------------------------------------------------ | --------------------------------------------------------------------------------------------- |
| [Supabase](/docs/compare/liveblocks-vs-supabase) | Postgres is your source of truth and you want a shared document, canvas, or board next to it. |
| [Firebase](/docs/compare/liveblocks-vs-firebase) | You use Firestore or Realtime Database and need collaborative editing, presence, or comments. |
| [Convex](/docs/compare/liveblocks-vs-convex)     | You run on Convex and are weighing its ProseMirror plugin against a full collaboration layer. |
